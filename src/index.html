Developer experience / R&D

Shared Component Library

Atomic component library used by 80% of Ansys product teams when building web applications. I helped architect the library from inception and now lead its technical direction.

Built with Angular and made available as Web Components and React wrappers, the library gives product teams a shared set of components across frameworks.

Application Template Repository & Agent Enablement

Led development of a GitHub template repository that brings together Ansys enablement technology and agent skills, helping stakeholders get web applications started more quickly.

Used by the design team to rapidly prototype and by stakeholders to set up application boilerplate quickly. In repeated trials, coding agents given a PNG reference and a short prompt consistently reused internal tooling for components, layouts, routing, Tailwind styling and other web app fundamentals.

Project Delivery & Administration Automation

To run the component library without a dedicated product owner, I took on project responsibilities and researched, designed and implemented a connected workflow for stakeholder requests, development, releases and reporting. Automating much of the repetitive administration saves many hours of manual work and gives developers more time to build.

GitHub Copilot can prepare routine changes from GitHub Issues, while GitHub Actions and Release Drafter help keep releases and reporting moving. Developers review every change before it is merged, and I review milestones and release summaries when needed.

Generated Component Documentation

Developers focus on building components and writing documentation inline with code, rather than creating documentation pages or duplicating API details by hand.

I built a documentation app that turns generated API specifications, derived from component structure and docstrings, into consistent pages and routes automatically. New components follow the same pattern without adding page-building work to feature development.

Design Language & Third-Party Integration

Worked with designers to deliver consistent UX across multiple web apps. A custom Tailwind configuration shares the design language, helping stakeholders build consistent applications beyond the component library.

Helped bring Ansys's design language to popular third-party packages, giving teams a consistent look and feel beyond the shared component library.

For Plotly, a theming service applies shared colours and fonts while developers configure and use Plotly directly. Similar packages extend shared styling to AG Grid, ngx-markdown and CodeMirror without duplicating their APIs.
